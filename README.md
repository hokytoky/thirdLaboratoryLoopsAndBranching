# Лабораторная работа: Расчет коэффициента лобового сопротивления сферы

## Автор
ФИО: Сабитов И.И.
Вариант: 28

## Цель
Освоение циклов с ветвлениями: цикла for для обработки серии значений и оператора if-else для выбора формулы на каждом шаге.

## Описание
Программа вычисляет число Рейнольдса и коэффициент лобового сопротивления сферы при обтекании жидкостью для серии скоростей. Формула для коэффициента выбирается по значению числа Рейнольдса.

## Исходные данные
Диаметр сферы: 3 мм
Вязкость жидкости: 0.014 см²/с
Скорости жидкости: 1, 2, 5, 7, 10 см/с

## Ожидаемые результаты
Программа выводит для каждой скорости:
C: коэффициент лобового сопротивления
Re: число Рейнольдса

w (cm/s)    C         Re
1           2.51012   21.4286
2           1.49253   42.8571
5           0.984172  107.143
7           0.889678  150
10          0.799396  214.286
